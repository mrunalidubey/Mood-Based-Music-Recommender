# Mood-Based Music Recommender 🎵

A Python project that recommends songs based on the user's mood.

## Features
- Mood-based song recommendation
- Random song suggestions
- Emoji reactions
- Artist suggestions

## Technologies Used
- Python
- VS Code

## How to Run
1. Open project in VS Code
2. Run `music.py`
3. Enter your mood

## Example Moods
- happy
- sad
- chill
- motivated
